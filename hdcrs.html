The Challenge

Construction Reporting is Broken

Across Ethiopia's public infrastructure projects, daily progress reporting still relies on manual, paper-based processes that create systemic inefficiencies and blind spots for decision-makers.

Delayed
Error

Manual Processes Create Cascading Failures

When Resident Engineers hand-write daily reports and Project Managers manually compile monthly summaries, the entire oversight chain suffers from delays, errors, and incomplete data.

Delayed Reporting

Paper reports take days to reach directors. By the time data arrives, it's already outdated and decisions are made on stale information.

Manual Calculation Errors

Cumulative progress, target achievement percentages, and block status are computed by hand — prone to mistakes that compound over time.

No Real-Time Visibility

Directors have no dashboard view. They rely on word-of-mouth or fragmented spreadsheets to understand project health.

No Audit Trail

When a report is revised, there's no record of what changed, who changed it, or why. Accountability is impossible to establish.

The Solution

What is HDCRS?

The Halbeeg Daily Construction Reporting System is a cloud-native web platform built on Google Apps Script that digitizes the entire construction reporting workflow — from field data entry by Resident Engineers to executive analytics dashboards for Directors.

Field Data Entry

Resident Engineers submit structured daily reports from any device with a browser. No installs, no paper.

Auto-Calculate Engine

Cumulative progress, target achievement %, and block status are computed automatically in real-time.

Director Analytics

9+ KPIs with 30-day trend charts. Directors see project health at a glance without reading a single report.

PDF Report Generation

One-click professional PDF reports with embedded photos, ready for government submission and archiving.

Core Capabilities

Engineered for Construction Reality

Every feature in HDCRS was designed to solve a real pain point observed on active government construction sites in the Somali Regional State of Ethiopia.

Auto-Calculate Engine

The heart of HDCRS. Every time a Resident Engineer submits a daily report, the engine automatically recalculates cumulative progress percentages, computes target achievement rates, and updates the overall block completion status — across all projects and all work items simultaneously.

Cumulative progress computed per work item and per project
Target achievement % auto-derived from planned vs. actual
Block status (Not Started / In Progress / Completed) auto-set
Recalculates across the entire project chain on every submission

Director Analytics Dashboard

A comprehensive KPI dashboard purpose-built for directors who need to monitor multiple construction projects simultaneously. Powered by Chart.js with interactive visualizations that load directly in the browser.

9+ KPIs: active projects, overall progress, workforce, equipment utilization
30-day rolling trend charts for every major metric
Project-level drill-down with status breakdowns
Real-time data — no refresh needed, always current

PDF Report Generation

Generate publication-ready daily and monthly reports as PDF documents with a single click. Reports include site photographs, progress tables, and all relevant metadata — formatted for government submission standards.

HTML-to-PDF pipeline via Google Apps Script blob service
Base64-encoded photos embedded directly into PDF output
Branded headers, footers, and consistent formatting
Downloadable and archivable for compliance records

Field-Level Audit Trail

Every edit to any report is tracked at the field level. The system records exactly which value changed, what the old and new values were, who made the change, and when. This creates an immutable chain of accountability across the entire reporting workflow.

Field-level diff tracking — not just "report was edited"
Old value, new value, editor identity, and timestamp recorded
Full revision history viewable per report
Supports accountability and dispute resolution

Technology

Built with Proven Stack

Every technology choice was driven by the constraints of the deployment environment: zero infrastructure budget, unreliable internet, and non-technical end users.

Google Apps Script

Serverless backend with built-in spreadsheet integration. Zero hosting cost.

Google Sheets

Relational database with 22 tabs. Parent-child via Report ID keys.

Vanilla HTML/JS/CSS

No frameworks. Fast load, works offline-capable, minimal dependencies.

Chart.js

Interactive analytics visualizations for the Director dashboard.

Role-Based Access

UI gating + server-side validation. RE, Director, PM roles.

localStorage

Client-side draft saving for field reports in low-connectivity areas.

Blob PDF Engine

HTML-to-PDF via Google blob service with base64 photo embedding.

Fully Cloud-Native

No servers, no Docker, no deployment pipeline. Push and go.

User Portals

Three Portals, One System

Each user role gets a purpose-built interface tailored to their specific workflow. All portals share the same backend and data layer, ensuring consistency.

Resident Engineer

RE Portal

The field data entry interface where Resident Engineers submit daily construction reports, upload site photographs, and track progress for each work item and block.

  • Structured daily report submission
  • Photo upload with base64 encoding
  • Auto-calculated progress indicators
  • Draft saving via localStorage
  • Report edit and revision history
Director

Director Portal

The executive analytics dashboard that gives directors real-time visibility into all active construction projects without needing to read individual reports.

  • 9+ KPI cards with live values
  • 30-day trend charts (Chart.js)
  • Project-level status breakdown
  • Workforce and equipment tracking
  • One-click PDF report download
Project Manager

PM Portal

The project management interface for PMs who need to oversee report quality, monitor team activity, and ensure data completeness across projects.

  • Cross-project progress comparison
  • Data completeness indicators
  • Export and archiving tools
